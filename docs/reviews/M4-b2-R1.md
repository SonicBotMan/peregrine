# M4-b2 R1 自查报告 — BT/magnet 引擎（librqbit embed）

日期：2026-09-14 · 轮次：开发 → R1（本文档）→ R2 独立审查 → 处置 → R3 → 提交

## 交付范围

PROPOSAL §4.3：BT 协议不自研，librqbit 以库嵌入，藏进与 HTTP/FTP/HLS 相同的 engine/port 分层。

### 面积

- `crates/engine-bt/src/lib.rs`（~290 行）：`BtEngine`（Session 惰性初始化，每 engine 一个）、`is_bt_source` 路由判定（magnet:/http(s)/file:// 的 .torrent、本地路径）、add→poll→outcome 映射、cancel→pause、purge。
- `crates/scheduler/src/bt_port.rs`：`BtAutoPort`（DownloadPort 适配：BT 无 probe 元数据、resume 语义 = rqbit overwrite 验证）。
- `crates/server/src/daemon.rs`：RoutingPort 增加 bt 分支。
- `crates/scheduler/src/tls.rs` + `crates/engine-http/src/lib.rs`：**rustls 双 provider 根治**——workspace 特性统一同时链入 ring（我们的选择）与 aws-lc-rs（librqbit→reqwest/rustls 无 ring 变体），auto-detection 失效；在 `https_client()` 构造点 + 三个二进制入口显式安装 ring provider。
- `crates/engine-bt/tests/local_torrent.rs`（5 测试）：路由判定全方言、本地 .torrent 元数据→cancel、**离线验证完成**（预置完整文件→overwrite 验证全部 piece→finished，零 peer 走通 add+verify+stats+outcome 全链）、**取消后重加自愈**（AlreadyManaged→unpause，poll loop 每 tick 重申 unpause 防晚到 pause）、purge 幂等。

### 契约决策

- **output_folder = sink.parent()**：BT 的 sink 是下载目录语义（torrent 文件名来自元数据，不可改名否则破坏 piece hash）。文档写明。
- **resume = overwrite 验证**：rqbit add 时重验既有 piece，peregrine 零自管状态；session 内重加返回 AlreadyManaged → unpause 续传。
- **cancel = pause**（文件保留，重加即续）；文件删除走 purge。
- **bytes_written 语义**：验证补偿场景下（异步验证完成时刻 vs add 返回时刻）可能 = 0 或 = total，皆合法；测试断言 `<= total` + 磁盘字节完整。

## R1 发现与处置

| # | 级别 | 发现 | 处置 |
| --- | ------ | ------ | ------ |
| 1 | P0 | **workspace 特性统一后 rustls 双 provider panic**（ring + aws-lc-rs 并存，engine-hls 15 测试 workspace 跑全挂、单跑绿——单 crate feature 解析只含 ring） | 根治在 `https_client()` 构造点安装 ring（生产/测试全 HTTP 路径自动覆盖）+ `scheduler::tls::init_tls()` 公共函数供二进制入口（cli/server/mcp main）与 bt 测试（librqbit 内部 reqwest 不走 https_client）显式调用 |
| 2 | P1 | pause/unpause 竞态：晚到的 pause（前一个 cancel 发出）可能落在新 download 的 unpause 之后 → 新下载永久暂停（paused torrent stats 永不 finished） | poll loop 每 tick `is_paused() → unpause` 自愈（幂等，成本 = 300ms 一次原子读）；新增测试 `cancelled_torrent_resumes_and_self_heals` |
| 3 | P1 | download 返回后 handle 泄漏 | **勘误（R2 F9）**：处置声明失真——`handle` 是局部变量，返回时必然 drop，从无泄漏；显式 `drop(handle)` 纯装饰。真实修复价值为零，R1 把误报记成 P1 已修，审查记录失真 |
| 4 | P2 | `is_bt_source` 不认 `file://…​.torrent` | scheme 白名单加 file |
