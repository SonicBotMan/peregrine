## 开发中发现的问题（已修）
1. **mock 漏写 MEDIA-SEQUENCE**（不是引擎 bug）：滑窗服务器必须递增 MEDIA-SEQUENCE，否则 seq 按窗口内 index 重编号，引擎把新窗口正确地去重为"已见"。POLL/SRV 双侧探针定位。教训：协议级测试 mock 必须逐字段对 RFC。
2. 单次 poll 网络抖动会杀死录制（P1，自查发现）：加 poll_failures 容错 + 间歇 503 测试。
