## 技术要点（本轮沉淀）

- **取消语义的三层覆盖**：请求阶段（每 redirect hop select cancel，biased）、
  body 帧阶段（STALL_TIMEOUT + cancel select）、轮询间隙（tick 后复查）。任何
  一层缺失都会让"取消必须及时"变成"通常及时"。
- **stall 判死用时间预算不用次数**：次数预算隐式耦合轮询节奏（cadence clamp
  到 8s 时 6 次=48s），时间预算（3×td clamp [1s,180s]）直接对齐协议语义
  （段最迟 td 出现）。td 缺省回退 2×cadence 与 cadence 推导式互逆。
- **错误分类即重试语义**：LiveStalled/SegmentGap → ApiError::Network（可重试），
  而不是 UnsupportedUrl/Internal。上游死流不是"URL 不支持"，空洞不是"内部错误"。
- **段级重试的真正理由**（R2 P1-3 的深层）：不是"503 常见"，而是未重试的失败段
  seq 滑出窗口后 → merge 报不可恢复的 segment gap——把瞬时故障升格成永久失败。
