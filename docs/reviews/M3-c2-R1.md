# M3-c1 R1 — 作者自查

范围：Tauri 2 壳骨架 + daemon TCP 面配套 + 前端运行时探测 + 完成通知。

## 交付物

1. **src-tauri/**（新 crate，独立 workspace——本机缺 webkit2gtk/dbus 系统库，
   `cargo check` 止步 libdbus-sys build script；CI `.github/workflows/desktop.yml`
   是唯一验证面）：
   - lib.rs：sidecar spawn（`--tcp 8420`，TCP-only：app 内 webview 说 HTTP/WS，
     app-bound UDS 无意义且会与 CLI 实例抢 socket）；stdout/stderr 转日志 +
     Terminated 事件上报；托盘（Show/Quit 菜单 + 左键点按切换窗口可见性）；
     关窗→隐藏（close-to-tray，daemon 继续下载）；单实例插件（二次启动聚焦）；
     Quit→app.exit(0)（plugin-shell 退出时杀 sidecar）。
   - main.rs：windows_subsystem 声明。
   - tauri.conf.json：980×700 窗口、trayIcon 配置、bundle deb/rpm/appimage、
     externalBin `binaries/peregrined`（CI 按 triple 暂存 release 产物）。
   - capabilities/default.json：`core:default + notification:default`
     （最小权限——sidecar 由 Rust 侧 spawn，JS 无 shell 权限）。
   - icons/：PIL 生成全套（falcon-dive 标记，与 web UI 同色板）。
2. **daemon TCP 面配套**（crates/server）：
   - api.rs `LOOPBACK_HOSTS` 加 `tauri.localhost`（Tauri webview 的 Linux/Windows
     origin；host_guard 白名单化）。
   - api.rs `with_tcp_cors`：CORS 仅 TCP 面（AllowOrigin 白名单
     tauri.localhost / tauri://localhost / localhost:5173，GET/POST/PATCH，host_guard
     仍在外层——双防线）。UDS 面不加（无 origin 概念）。
   - main.rs TCP 分支 layer 顺序 host_guard → cors（preflight OPTIONS 过 guard
     后由 CORS 层应答）。
3. **前端**（apps/desktop/src）：
   - daemon.ts `detectBases()`：`__TAURI_INTERNALS__` 探测 → Tauri 用
     `http://127.0.0.1:8420` 裸路径（`/api` 前缀只存在于 vite proxy，proxy 会剥掉）；
     浏览器维持相对路径。
   - notify.ts：完成通知（动态 import plugin-notification，非 Tauri 环境静默
     no-op；权限被拒/通道异常绝不抛——展示层锦上添花不应影响下载功能）。
   - store.svelte.ts `createStore` 加可选 `onCompleted` 钩子（task_completed 事件
     触发；表现层职责不进 store 本体）。
   - App.svelte：detectBases 接线 + 通知回调（从 list 找行取 url 派生文件名）。
4. **CI** desktop.yml：apt 装 webkit2gtk/appindicator → pnpm install →
   `cargo build -p peregrine-server --release` → 按 triple 暂存 sidecar →
   `pnpm exec tauri build --bundles deb,appimage` → artifact 上传。

## 自查发现与修复（写报告时已修）

- **F1（P0，已修）**：detectBases 初版 Tauri 分支写成 `http://127.0.0.1:8420/api`
  ——`/api` 前缀是 vite proxy 约定，proxy 剥掉后 daemon 是裸路由
  （api.rs `/tasks` 等无前缀）。真机 curl 复现 404 后修正为裸 base。
  若未发现：Tauri 构建后整个 UI 全部请求 404。
- **F2（P1，已修）**：tower-http 初次误加入 dev-dependencies（edit 落点错位，
  与既有 dev 段 tower 相邻）→ lib 编译失败，移入主依赖。
- **F3（P1，已修）**：src-tauri 无 `[workspace]` 标记时 cargo 把它当作父 workspace
  成员（虽然未列 members）→ 本机 workspace 全套命令连带失败。加空 `[workspace]`。
- **F4（P2，已修）**：capabilities 初版给了 shell:allow-spawn/execute——sidecar
  由 Rust 侧 spawn，JS 层不需要。最小权限化。

## 已知限制（记录不隐瞒）

- **本机不可编译验证 src-tauri**：webview/dbus 系统库缺失（无 sudo，apt 不可用）。
  代码正确性由 CI workflow 首跑验证；R2 对 Tauri 2 API 用法做 registry 源码级
  静态核对作为补偿。
- **通知文案的 pct**：`task_completed` 事件先于 REST 回读到达，瞬间查 list 可能
  拿到 99% ——展示层锦上添花，接受（下次刷新即正）。
- 托盘图标菜单 Quit 前未等待 daemon flush：sidecar 由 plugin-shell 托管，
  app 退出即 kill；running 任务已由 engine 每 tick 落盘（M1 起），kill 丢失窗口
  ≤1 个 chunk（与 M2 崩溃恢复语义一致）。
